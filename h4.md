1) Pilvipalvelimen vuokraus ja asennus

- Vuokraa pilvipalvelin haluamaltasi palveluntarjoajalta.

- Luo palvelinta luodessa SSH-avain kirjautumista varten.

2) Palvelimen suojaus palomuurilla

- Yhdistä palvelimeen SSH:n avulla:

ssh root@<palvelimen_IP>


- Päivitä palvelin:

sudo apt-get update


- Asenna UFW-palomuuriohjelma:

sudo apt-get install ufw


- Ota palomuuri käyttöön:

sudo ufw enable

3) Kotisivut palvelimelle

- Luo uusi käyttäjä (esim. suska) ja lisää hänet sudo-ryhmään.

- Asenna Apache-webpalvelin ja avaa portti 80 palomuurissa.

- Korvaa Apachen oletussivu (“Hello world!”) omalla testisivulla.

- Ota käyttöön userdir-moduuli ja luo public_html-kansio käyttäjälle.

- Luo käyttäjän kotisivu (index.html) ja varmista, että se toimii selaimessa.

4) Palvelimen ohjelmien päivitys

- Yhdistä palvelimeen SSH:n kautta.

- Hae päivitystiedot:

sudo apt-get update


- Asenna normaalit päivitykset:

sudo apt-get upgrade


- Asenna jakelupäivitykset:

sudo apt-get dist-upgrade


- Varmista, että palvelin on ajan tasalla tietoturvan kannalta.
