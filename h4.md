1) Pilvipalvelimen vuokraus ja asennus

- Valitsi DigitalOceanin GitHub Student Developer Packin avulla

- Loi Dropletin (Debian 11, 1 GB RAM, 25 GB SSD) Amsterdamin konesaliin

- Valitsi kirjautumistavaksi salasanan (ei SSH-avaimia)

- Vuokrasi .me-domainin Namecheapilta (susannalehto.me)

- Ohjasi domainin DigitalOceanin palvelimen IP-osoitteeseen A-tietueilla

2) Palvelin suojaan palomuurilla

- Otti SSH-yhteyden palvelimeen (ssh root@188.166.4.6)

- Päivitti pakettilistat (sudo apt-get update)

- Asensi UFW-palomuurin (sudo apt-get install ufw)

- Avasi SSH-portin palomuuriin (portti 22)

- Otti palomuurin käyttöön (sudo ufw enable)

3) Kotisivut palvelimelle

- Loi uuden käyttäjän (suska) ja lisäsi hänet sudo-ryhmään

- Asensi Apache-webpalvelimen ja avasi portin 80 palomuuriin

- Korvasi Apachen testisivun “Hello world!” -sivulla

- Otti käyttöön userdir-moduulin ja loi public_html-kansion

- Loi käyttäjän kotisivun (index.html) ja varmisti sen toimivan selaimessa

4) Palvelimen ohjelmien päivitys

- Otti SSH-yhteyden palvelimeen

- Haki päivitystiedot (sudo apt-get update)

- Asensi normaalit päivitykset (sudo apt-get upgrade)

- Asensi jakelupäivitykset (sudo apt-get dist-upgrade)

- Varmisti, että palvelin oli ajan tasalla tietoturvan kannalta
