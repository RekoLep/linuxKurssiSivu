a)

Tässä harjoituksessa tuli kirjoittaa ja ajaa "Hei maailma" kolmella eri ohjelmointikielellä. Päätin kirjoittaa lausahdukseni Java-, Python- ja C-kielillä.

Kun tein Javalla, päivitin ensin pakettiluettelon komennolla sudo apt update ja asensin sitten Java Development Kitin komennolla sudo apt install default-jdk. Loin tiedoston hei.java, kirjoitin siihen yksinkertaisen Java-ohjelman ja käänsin sen javac hei.java -komennolla. Lopuksi ajoin ohjelman komennolla java hei, jolloin terminaali tulosti Hei maailma.
