The Apache Software Foundation 2023: Apache HTTP Server Version 2.4 Documentation:

- Name-based vs. IP-based Virtual Hosts: Nimiin perustuvat virtuaalipalvelimet mahdollistavat useiden verkkotunnusten käyttämisen samalla IP-osoitteella HTTP-otsikoiden avulla, kun taas IP-pohjaiset vaativat erillisen IP:n per sivusto.

- Miten Apache valitsee virtuaalipalvelimen: Ensin valitaan paras IP/portti-osuma, sitten verrataan ServerName- ja ServerAlias-arvoja; jos mikään ei täsmää, käytetään ensimmäistä määriteltyä virtuaalipalvelinta.

- Name-based Virtual Hostien määrittäminen: Jokaiselle sivustolle luodaan <VirtualHost>-lohko, jossa vähintään ServerName ja DocumentRoot; ServerAlias mahdollistaa useat verkkotunnukset samalle sivulle.

- Parhaat käytännöt ja huomautukset: Määrittele ServerName aina eksplisiittisesti, huomioi periytyminen globaalista konfiguraatiosta, ja varmista että DNS osoittaa nimet oikeaan IP-osoitteeseen.

Karvinen 2018: Name Based Virtual Hosts on Apache – Multiple Websites to Single IP Address

- Apache mahdollistaa useiden verkkotunnusten ajamisen yhdellä IP-osoitteella (name-based virtual hosting), kun käytössä on yksi palvelin ja monta sivustoa.

- Asennus ja perusasetukset: Asenna Apache, korvaa oletussivu ja luo uusi <VirtualHost>-konfiguraatio ServerName-, ServerAlias- ja DocumentRoot-määrityksillä.

- Virtuaalipalvelimen käyttöönotto: Aktivoi sivusto (a2ensite), käynnistä Apache uudelleen ja luo sivuston tiedostot normaalina käyttäjänä omassa hakemistossa.

- Testaus ja DNS-simulaatio: Testaa curl-komennolla Host-otsikkoa käyttäen ja simuloi domain-nimiä /etc/hosts-tiedostolla; voit lisätä rajattomasti uusia virtuaalipalvelimia yhdelle IP:lle.

1. 127.0.0.1 — IP-osoite

Pyynnön lähettäjän IP-osoite.
127.0.0.1 tarkoittaa localhostia, eli pyyntö tuli omalta koneeltasi.

2. - — Remote logname

Vanha RFC-kenttä käyttäjän tunnistukseen.
Lähes aina -, koska sitä ei käytetä nykyjärjestelmissä.

3. - — Authenticated user

HTTP-autentikoitu käyttäjä.
- tarkoittaa, että kirjautumista ei käytetty.

4. [31/Jan/2026:08:40:27 +0200] — Aikaleima

Päivämäärä ja kellonaika, jolloin pyyntö tehtiin.

31 = päivä

Jan = tammikuu

2026 = vuosi

08:40:27 = aika

+0200 = aikavyöhyke (Itä-Euroopan aika)

5. "GET / HTTP/1.1" — HTTP-pyyntö

Tämä kenttä sisältää kolme osaa:

GET = HTTP-metodi (haetaan dataa)

/ = pyydetty resurssi (etusivu)

HTTP/1.1 = HTTP-protokollan versio

Eli: selain pyysi Apachelta etusivua

6. 200 — HTTP-statuskoodi

Status 200 OK tarkoittaa:

Pyyntö onnistui ja sivu toimitettiin oikein.

(Tämä kertoo, että palvelin toimi ilman virheitä.)

7. 3383 — Vastauksen koko (tavuina)

Apache lähetti selaimelle 3383 tavua dataa.
Tämä on ladatun HTML-sivun koko.

8. "-" — Referer

Kertoo, miltä sivulta käyttäjä tuli.
- tarkoittaa, että:

sivu avattiin suoraan

tai referer-tietoa ei lähetetty

9. "Mozilla/5.0 (X11; Linux x86_64; rv:140.0) Gecko/20100101 Firefox/140.0" — User-Agent

Tunnistaa selaimen ja käyttöjärjestelmän:

Mozilla/5.0 = selainyhteensopivuusmerkintä

X11; Linux x86_64 = Linux 64-bit

rv:140.0 = Firefoxin versio

Gecko = selainmoottori

Firefox/140.0 = käytetty selain
